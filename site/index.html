Reels, edited and posted
by your AI.

Drop your raw talking-head takes in a folder. Tell Claude or ChatGPT what you want. Review the cut. It adds native captions and headers in Instagram Edits on your iPhone and posts it — the same way, every time.

Install on macOS Source on GitHub

Install

curl -fsSL https://raw.githubusercontent.com/LochlanMacQueen/auto-edit/main/install.sh | bash
Apple Silicon Mac, macOS 26. Installs ffmpeg + whisper, starts the local server, opens the dashboard at 127.0.0.1:4747. Then install Palmier Pro (the editor) and connect Claude from the dashboard.

How it works

  1. Put your files in a folder — takes, images, a song, a reference reel.
  2. Tell your agent exactly what you want — structure, what's on screen when, length, music.
  3. Review — the clean cut lands in the dashboard; approve or send notes.
  4. Edits + post — native captions and headers in Instagram Edits on your phone, shared from Instagram (normal or trial reel), spaced out however you like.
One MCP server29 tools: transcribe, dead-space cuts with false-start detection, Palmier Pro timeline builds, export, music bake, verification, review, phone jobs, posting queue.
Works withClaude Desktop (one-click extension), Claude Code, ChatGPT (via tunnel), Cursor, Codex.
Native reachCaptions and headers are real Instagram Edits text, and the post is shared from the Instagram app — not an API upload.

Open source (GPL-3.0). Built on Palmier Pro and Phone Farm iOS.
